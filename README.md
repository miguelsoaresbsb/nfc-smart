# NFC Smart

SaaS para páginas permanentes vinculadas a TAGs NFC. Next.js + Supabase + Vercel.

## Regras
- QR Codes são enviados como imagens existentes; o sistema não gera nem lê QR.
- URL pública é permanente.
- Dados de cada empresa devem ser isolados por RLS.
- Modelo comercial: R$80,00 pela plaquinha física NFC (pagamento único) + R$30,00/mês pelo acesso e manutenção da plataforma digital.
- O checkout recorrente da Cakto e a ativação/cancelamento mensal precisam estar configurados antes de receber pagamentos pelo novo modelo.
